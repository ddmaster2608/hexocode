# git 将本地仓库上传至github

```bush

先建立连接
git add .
git commit -m "任意"
git push origin main
PS.如果不行 先执行 git pull origin main
另外 本地添加文件夹时，要删掉git隐藏文件夹，再上传，//注意要先cd到目标文件夹，再 add .
```
